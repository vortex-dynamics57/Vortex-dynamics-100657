ARCSTEEL — VORTEX Dynamics website assistant (prototype)

FILES
- arcsteel-test.html: a standalone demo page for testing the chat UI without touching the live website.
- arcsteel-widget.txt: the chat widget code to add to a copied/test version of the existing site.

IMPORTANT
This is version 1 and uses predefined answers. It is not connected to a live AI model and does not learn from chats.

SAFE TESTING
1. Open arcsteel-test.html in a browser to try the interface.
2. To integrate with a copied GitHub repository, open its index.html.
3. Paste the full contents of arcsteel-widget.txt immediately before the final </body> tag.
4. Commit only to the TEST repository, enable GitHub Pages there, and test the published copy.
5. Do not edit the original live repository until the test is working.

SECURITY
Do not put API keys or private credentials in HTML/JavaScript. A future generative AI version needs a server-side backend or a trusted AI provider integration.
